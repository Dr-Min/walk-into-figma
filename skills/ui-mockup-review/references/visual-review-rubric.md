# Visual Review Rubric

## Representative set

Select the smallest set that answers the design questions:

- primary/home or discovery surface;
- detail or task surface;
- core interaction surface;
- monetization or permission surface if central;
- one loading, empty, error, locked, or overlay state;
- mobile and desktop example when both are in MVP.

## Review dimensions

Score each candidate `pass`, `revise`, or `reject`:

1. Requirement and screen-ID match
2. Information hierarchy
3. Primary-action clarity
4. Navigation scalability
5. Content realism
6. State visibility
7. Component consistency
8. Responsive plausibility
9. Accessibility risk
10. Brand and emotional fit

| File | Screen/state | Status | Decision | Reusable patterns | Date |
|---|---|---|---|---|---|

## Approval note

Record what is approved, not merely that an image is approved:

- layout model;
- navigation behavior;
- palette and theme;
- typography character;
- spacing/density;
- image treatment;
- components to reproduce;
- elements specifically rejected.
